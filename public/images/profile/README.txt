=======================================================
📸 PANDUAN MENARUH FOTO PROFIL ANDA (PROFILE PHOTO)
=======================================================

1. Masukkan file foto Anda ke dalam folder ini:
   public/images/profile/

2. Anda bisa menamai foto Anda "avatar.jpg" (menimpa avatar bawaan),
   ATAU
3. Memberi nama foto baru (misal: "my-photo.png"), lalu buka file:
   src/data/portfolio.ts
   dan ubah:
   avatarUrl: "/images/profile/my-photo.png"

Website akan langsung otomatis menampilkan foto Anda dengan bingkai neon glowing yang elegan!
