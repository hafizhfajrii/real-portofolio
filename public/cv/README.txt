=======================================================
📄 PANDUAN MENARUH FILE CV / RESUME PDF ANDA
=======================================================

1. Masukkan file PDF CV Anda ke dalam folder ini:
   public/cv/

2. Anda bisa menamai file PDF Anda:
   "Hafizh-Resume.pdf" (menimpa file PDF bawaan),
   
   ATAU jika memberi nama lain (misal: "CV-Hafizh-2026.pdf"), buka file:
   src/data/portfolio.ts
   dan ubah:
   resumeUrl = "/cv/CV-Hafizh-2026.pdf";

3. Ketika tombol "CV / Resume" diklik di Navbar atau halaman web, browser akan langsung membuka file PDF CV Anda di tab baru!
